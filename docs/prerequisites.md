# Prerequisites

[← Back to README](../README.md)

Basic familiarity with the following will help you get the most out of this repository.

| Area | What you need |
|------|---------------|
| Linux | Fundamentals and command-line operations |
| YAML | Basic syntax (indentation, lists, dictionaries) |
| SSH | Remote connectivity and key-based authentication |
| AWS | Basic knowledge, required only for the EC2 module (03) |
| Git/GitHub | Cloning, committing, pushing (needed for modules 10 and 12) |

## Suggested Lab Setup

- A control node (Linux/macOS/WSL) with Ansible installed
- One or more managed nodes reachable over SSH (VMs, containers, or EC2)
- An AWS account for module 03
- A GitHub account and Galaxy login for modules 09 to 12
