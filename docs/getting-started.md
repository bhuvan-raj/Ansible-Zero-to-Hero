# Getting Started

[← Back to README](../README.md)

## 1. Clone the repository

```bash
git clone https://github.com/bhuvan-raj/Ansible-Zero-to-Hero.git
cd Ansible-Zero-to-Hero
```

## 2. Check your prerequisites

See [Prerequisites](./prerequisites.md).

## 3. Work through a module

```
   Read module README  -->  Run the examples  -->  Do the lab/exercise
            ^                                              |
            +------------- review and repeat --------------+
```

Each module folder has its own `README.md` with explanations, examples, and hands-on exercises. Follow the order in the [Learning Path](./learning-path.md) if you are new to Ansible.
